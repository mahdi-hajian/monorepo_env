# Triage Labels

Skills use five triage roles. This file maps roles to real label strings in issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                    |
| -------------------------- | -------------------- | -------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer must evaluate   |
| `needs-info`               | `needs-info`         | Wait for reporter info     |
| `ready-for-agent`          | `ready-for-agent`    | Ready for AFK agent        |
| `ready-for-human`          | `ready-for-human`    | Needs human                |
| `wontfix`                  | `wontfix`            | No action                  |

When skill mention role (e.g. "apply AFK-ready triage label"), use label string from this table.

Edit right column to match your words.
