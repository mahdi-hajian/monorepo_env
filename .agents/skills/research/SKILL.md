Spin up **background agent** do research. You keep working while it reads.

Its job:

1. Investigate question against **primary sources** — official docs, source code, specs, first-party APIs — not secondary write-up. Follow each claim back to source that owns it.
2. Write findings to single Markdown file, cite each claim's source.
3. Save where repo already keeps such notes; match existing convention. If none, put somewhere sensible, say where.
