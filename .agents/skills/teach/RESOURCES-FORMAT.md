# RESOURCES.md Format

`RESOURCES.md` = curated set of trusted sources for topic. Explainers draw knowledge from here, not parametric guesses. Wisdom from communities listed here.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ — Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" — Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Rules

- **High-trust only.** Prefer primary sources, recognised experts, peer-reviewed work, communities with strong moderation. If marketing dressed as education, leave out.
- **Annotate every entry.** Bare link useless in three months. Add one line: what it covers, when to reach for it.
- **Group by Knowledge / Wisdom.** Mirrors philosophy in [SKILL.md](./SKILL.md). Fine for resource to appear in only one group.
- **Surface gaps explicitly.** If no good resource for area mission needs, write `## Gaps` section listing what is missing. Drives future search.
- **Prune ruthlessly.** Resource wrong, shallow, or off-mission: remove, not bury. Better five sharp sources than thirty mediocre ones.
- **Record community preferences.** If user opted out of joining communities, note here so future sessions don't keep proposing.
