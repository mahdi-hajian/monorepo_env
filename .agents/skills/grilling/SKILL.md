---
name: grilling
description: Grill the user relentlessly about a plan, decision, or idea. Use when the user wants to stress-test their thinking, or uses any 'grill' trigger phrases.
disable-model-invocation: true
---
Interview me relentless bout every aspect till shared understanding. Walk each branch of decision tree. Resolve dependencies one-by-one. Each question, give recommended answer.

Ask questions one at a time. Wait for feedback on each before next. Many questions at once = bewilder.

If *fact* can be found by exploring environment (filesystem, tools, etc.), look up. No ask me. *Decisions* mine — ask me each, wait for answer.

No act till I confirm shared understanding.
