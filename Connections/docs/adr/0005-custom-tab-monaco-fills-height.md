# Custom Tab: Monaco fills height; actions under it; pane resizable

Per the [advanced-connection Figma](https://www.figma.com/design/nPCTIkotM0luhtdADTe2VU/%25D9%2585%25D9%2588%25D8%25AF-%25D9%25BE%25DB%258C%25D8%25B4%25D8%25B1%25D9%2581%25D8%25AA%25D9%2587-%25D8%25A7%25D8%25AA%25D8%25B5%25D8%25A7%25D9%2584?node-id=3-735), Custom Tab Layout stretches Monaco to the available settings height, keeps existing buttons and checkboxes only beneath it, and makes the settings splitter pane resizable. Min width stays the current default (`400px`); max is current + `100px` (`500px`).
