# 02 — اتصال PostgreSQL و نمایش همیشگی SQL Server و PostgreSQL

Jira: TECSDM-122156

**What to build:** کاربر بتواند PostgreSQL را مثل SQL Server روی صفحه ساخت اتصال بسازد و مدیریت کند؛ و در پایان این فاز، هر دو نوع SQL Server و PostgreSQL همیشه در لیست نوع اتصال دیده شوند (بدون نیاز به روشن کردن قابلیت جدا).

**Blocked by:** 01 — اتصال SQL Server روی صفحه ساخت اتصال

**Status:** ready-for-agent

## Acceptance criteria / DoD

- [ ] در لیست نوع اتصال، PostgreSQL با آیکن آشنا دیده می‌شود.
- [ ] فرم شامل نام سرور، درگاه (پیش‌فرض ۵۴۳۲)، نام کاربری، کلمه عبور، نام پایگاه داده (متنی)، و «نمایش همه طرح‌ها» (پیش‌فرض خاموش) است.
- [ ] آزمایش اتصال، بروزرسانی جداول، ویوور، و ذخیره با/بدون بروزرسانی خودکار هنگام استفاده مثل SQL Server و بقیه انواع کار می‌کند.
- [ ] ذخیره و باز کردن اتصال PostgreSQL از همین صفحه ممکن است.
- [ ] پس از اتمام این فاز، SQL Server و PostgreSQL بدون قابلیت جدا، همیشه در لیست نوع اتصال کنار Oracle و StarRocks دیده می‌شوند.
- [ ] تست‌های واحد مرتبط سبز هستند.
