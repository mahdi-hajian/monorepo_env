# 01 — اتصال SQL Server روی صفحه ساخت اتصال

Jira: TECSDM-122155

**What to build:** کاربر بتواند در صفحه ساخت/ویرایش اتصال BDMP، وقتی قابلیت نمایش انواع رابطه‌ای روشن است، نوع SQL Server را ببیند و انتخاب کند؛ مشخصات سرور و پایگاه داده را پر کند؛ آزمایش اتصال و بروزرسانی جداول را انجام دهد؛ جداول را در همان ویوور آشنا ببیند؛ و اتصال را با یا بدون بروزرسانی خودکار هنگام استفاده ذخیره کند.

**Blocked by:** None — can start immediately.

**Status:** closed

## Acceptance criteria / DoD

- [x] در لیست نوع اتصال (با قابلیت روشن)، SQL Server با آیکن آشنا دیده می‌شود.
- [x] فرم شامل نام سرور، درگاه (پیش‌فرض ۱۴۳۳)، نام کاربری، کلمه عبور، نام پایگاه داده (متنی)، و «نمایش همه طرح‌ها» (پیش‌فرض خاموش) است.
- [x] چک‌باکس بروزرسانی خودکار هنگام استفاده و دکمه‌های آزمایش اتصال و بروزرسانی مثل بقیه انواع کار می‌کنند.
- [x] ویوور جداول همان تجربهٔ Oracle/StarRocks است.
- [x] ذخیره اتصال SQL Server موفق است و بعداً قابل باز کردن/ویرایش از همین صفحه است.
- [x] قابلیت SSL و گزینه‌های مخصوص Oracle/StarRocks در این فرم دیده نمی‌شوند.
- [x] وقتی قابلیت نمایش خاموش است، SQL Server در لیست نوع اتصال دیده نمی‌شود.
- [ ] تست‌های واحد مرتبط با این رفتار سبز هستند. (نوشته شده؛ اجرا نشده مگر درخواست شود)

## Comments
