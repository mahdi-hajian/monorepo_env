# 01 — جابه‌جایی یک آیتم با کشیدن روی پوشه

Jira: TECSDM-158871

**What to build:** در نمای کاشی، کاربر یک فایل یا پوشه را روی کاشی پوشهٔ دیگر بکشد و رها کند تا جابه‌جا شود؛ لیست تازه شود؛ روی browse فعلی بماند؛ خطای سرور مثل Paste دیده شود؛ بدون پیش‌چک collision نام در فرانت.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] کشیدن یک فایل روی پوشه، آن را داخل مقصد می‌برد
- [ ] کشیدن یک پوشه روی پوشهٔ دیگر، آن را داخل مقصد می‌برد
- [ ] بعد از موفقیت لیست refresh می‌شود و مسیر فعلی عوض نمی‌شود
- [ ] خطای سرور به شکل قابل‌فهم (هم‌سبک Paste) دیده می‌شود
- [ ] OS upload DnD و Copy در این تیکت نیست
