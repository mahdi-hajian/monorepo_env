Parent: TECSDM-122084  
Status: done

**What to build:** همان تجربه SQL Server برای PostgreSQL: انحصار، اتصال ذخیره‌شده، schema سپس جدول، نگاشت و ذخیره.

**Blocked by:** 01 / TECSDM-122144 ؛ 02 / TECSDM-122145

## Definition of Done

- [x] در طراحی منبع Record تب/بخش PostgreSQL دیده می‌شود
- [x] در منبع فایل و مجازی قابل انتخاب نیست
- [x] با روشن کردن PostgreSQL هیچ تکنولوژی دیگری همزمان روشن نمی‌ماند
- [x] با روشن بودن PostgreSQL تب‌های Elastic و Oracle غیرفعال‌اند
- [x] فقط اتصال ذخیره‌شده نوع PostgreSQL در لیست می‌آید
- [x] جریان اتصال → schema → جدول → نگاشت مثل SQL Server کار می‌کند
- [x] ذخیره منبع جدید PostgreSQL موفق است
- [x] در ویرایش منبع موجود تنظیمات قفل است
- [x] عنوان‌های محصولی PostgreSQL در UI هست
- [x] تست رفتار تب PostgreSQL پوشش داده شده
