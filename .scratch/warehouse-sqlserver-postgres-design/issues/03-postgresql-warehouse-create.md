# 03 — ساخت منبع داده PostgreSQL از طراحی منبع

Jira: TECSDM-122146  
Parent: TECSDM-122084  
Status: ready-for-agent

**What to build:** همان تجربه SQL Server برای PostgreSQL: انحصار، اتصال ذخیره‌شده، schema سپس جدول، نگاشت و ذخیره.

**Blocked by:** 01 / TECSDM-122144 ؛ 02 / TECSDM-122145

## Definition of Done

- [ ] در طراحی منبع Record تب/بخش PostgreSQL دیده می‌شود
- [ ] در منبع فایل و مجازی قابل انتخاب نیست
- [ ] با روشن کردن PostgreSQL هیچ تکنولوژی دیگری همزمان روشن نمی‌ماند
- [ ] با روشن بودن PostgreSQL تب‌های Elastic و Oracle غیرفعال‌اند
- [ ] فقط اتصال ذخیره‌شده نوع PostgreSQL در لیست می‌آید
- [ ] جریان اتصال → schema → جدول → نگاشت مثل SQL Server کار می‌کند
- [ ] ذخیره منبع جدید PostgreSQL موفق است
- [ ] در ویرایش منبع موجود تنظیمات قفل است
- [ ] عنوان‌های محصولی PostgreSQL در UI هست
- [ ] تست رفتار تب PostgreSQL پوشش داده شده
