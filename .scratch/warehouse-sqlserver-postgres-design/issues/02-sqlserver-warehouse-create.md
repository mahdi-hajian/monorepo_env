# 02 — ساخت منبع داده SQL Server از طراحی منبع

Jira: TECSDM-122145  
Parent: TECSDM-122084  
Status: done

**What to build:** طراح بتواند در ساخت منبع Record، SQL Server را انتخاب کند؛ با اتصال ذخیره‌شده، schema سپس جدول، نگاشت ستون و ذخیره. انحصار کامل مثل StarRocks؛ ساخت اتصال جدید از این مسیر نیست.

**Blocked by:** 01 / TECSDM-122144

## Definition of Done

- [x] در طراحی منبع Record تب/بخش SQL Server دیده می‌شود
- [x] در منبع فایل و مجازی قابل انتخاب نیست
- [x] با روشن کردن SQL Server بقیه تکنولوژی‌ها خاموش می‌شوند
- [x] فقط اتصال خارجی و اتصال ذخیره‌شده؛ ساخت اتصال جدید فعال نیست
- [x] بعد از اتصال: ابتدا schema سپس جدول
- [x] عوض کردن اتصال/schema انتخاب‌های بعدی را پاک یا به‌روز می‌کند
- [x] بعد از جدول، نگاشت ستون ممکن است
- [x] ذخیره منبع جدید SQL Server موفق است
- [x] در ویرایش منبع موجود تنظیمات قفل است
- [x] عنوان‌های محصولی SQL Server در UI هست
- [x] تست رفتار تب SQL Server پوشش داده شده
