# 02 — ساخت منبع داده SQL Server از طراحی منبع

Jira: TECSDM-122145  
Parent: TECSDM-122084  
Status: ready-for-agent

**What to build:** طراح بتواند در ساخت منبع Record، SQL Server را انتخاب کند؛ با اتصال ذخیره‌شده، schema سپس جدول، نگاشت ستون و ذخیره. انحصار کامل مثل StarRocks؛ ساخت اتصال جدید از این مسیر نیست.

**Blocked by:** 01 / TECSDM-122144

## Definition of Done

- [ ] در طراحی منبع Record تب/بخش SQL Server دیده می‌شود
- [ ] در منبع فایل و مجازی قابل انتخاب نیست
- [ ] با روشن کردن SQL Server بقیه تکنولوژی‌ها خاموش می‌شوند
- [ ] فقط اتصال خارجی و اتصال ذخیره‌شده؛ ساخت اتصال جدید فعال نیست
- [ ] بعد از اتصال: ابتدا schema سپس جدول
- [ ] عوض کردن اتصال/schema انتخاب‌های بعدی را پاک یا به‌روز می‌کند
- [ ] بعد از جدول، نگاشت ستون ممکن است
- [ ] ذخیره منبع جدید SQL Server موفق است
- [ ] در ویرایش منبع موجود تنظیمات قفل است
- [ ] عنوان‌های محصولی SQL Server در UI هست
- [ ] تست رفتار تب SQL Server پوشش داده شده
