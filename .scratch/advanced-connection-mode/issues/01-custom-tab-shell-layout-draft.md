# 01 — نمایش تب‌های اتصال ساده و اتصال سفارشی

**چه چیزی ساخته شود:** روی صفحه ایجاد/ویرایش اتصال، کاربر دو تب «اتصال ساده» و «اتصال سفارشی» را می‌بیند. در اتصال سفارشی، ویرایشگر JSON با مقدار اولیه خالی باز می‌شود، ارتفاع صفحه را پر می‌کند و زیر آن دکمه‌های آزمایش اتصال و به‌روزرسانی به‌همراه فقط گزینه «هنگام استفاده از اتصال، به‌روزرسانی خودکار انجام شود» قرار می‌گیرد. عرض پنل تنظیمات کمی قابل تنظیم است. جابه‌جایی بین تب‌ها نوشته‌های نیمه‌کاره را پاک نمی‌کند. رفتار اتصال ساده مثل امروز می‌ماند؛ ذخیره کامل اتصال سفارشی در این تیکت لازم نیست.
