# 02 — Opaque REST Probe + نمایشگر مبتنی بر کاتالوگ

**چه چیزی ساخته شود:** از تب سفارشی، آزمایش اتصال و پیش‌نمایش دیتاسورس با Opaque REST Probe انجام شود (قبل از ذخیره با Payload خام؛ بعد از ذخیره با شناسه اتصال). پیش‌نمایش موفق پنل چپ را با نمایشگر مبتنی بر کاتالوگ پر کند. خطاهای سرور همان‌طور که برگشته‌اند نمایش داده شوند.
