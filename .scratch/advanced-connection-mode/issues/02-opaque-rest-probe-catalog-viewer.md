# 02 — آزمایش اتصال و پیش‌نمایش جداول در اتصال سفارشی

**چه چیزی ساخته شود:** از تب اتصال سفارشی، کاربر بتواند قبل از ذخیره با همان JSON واردشده، اتصال را آزمایش کند و فهرست جداول را ببیند. بعد از ذخیره، همین کارها با شناسه اتصال ذخیره‌شده انجام شود. بعد از پیش‌نمایش موفق، پنل جداول پر می‌شود و نوع نمایشگر از پاسخ سرور مشخص می‌شود. پیام خطای سرور همان‌طور که برگشته نمایش داده می‌شود.

**مسدودکننده:** TECSDM-121819 — نمایش تب‌های اتصال ساده و اتصال سفارشی

**Status:** ready-for-agent

**Parent:** TECSDM-121817  
**Spec:** `.scratch/advanced-connection-mode/spec.md`  
**Jira:** [TECSDM-121820](https://jira.mohaymen.ir/browse/TECSDM-121820)

## معیار پذیرش

- [ ] قبل از ذخیره، آزمایش اتصال با محتوای ویرایشگر JSON کار کند
- [ ] قبل از ذخیره، پیش‌نمایش فهرست جداول را در پنل سمت دیگر نشان دهد
- [ ] بعد از ذخیره، آزمایش و پیش‌نمایش با شناسه اتصال ذخیره‌شده کار کنند
- [ ] نوع نمایشگر جداول از پاسخ پیش‌نمایش انتخاب شود، نه از نوع اتصال ساده
- [ ] خطاهای سرور (از جمله رد چند پایگاه‌داده) بدون قاعده اضافه در کلاینت نمایش داده شوند
